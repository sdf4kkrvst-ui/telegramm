# All Be Goods — автопостинг в Telegram

Публикует один пост в час в канал [@allbegoods](https://t.me/allbegoods) через GitHub Actions — работает в облаке GitHub, не зависит от вашего компьютера и не зависит от сети в России (запрос идёт с сервера GitHub).

## Как это устроено

- `posts_bank.json` — банк из 50 готовых оригинальных постов (факты, история, юмор и т.д.), у части есть привязанное бесплатное фото с Unsplash.
- `post.py` — при каждом запуске берёт следующий ещё не опубликованный пост из банка и публикует его в канал. Когда банк заканчивается — начинает заново со случайным порядком.
- `posted_state.json` — создаётся и обновляется автоматически, хранит, что уже опубликовано (коммитится обратно в репозиторий самим workflow).
- `.github/workflows/telegram-post.yml` — расписание: запуск каждый час (`cron: '3 * * * *'`), плюс кнопка ручного запуска в вкладке Actions.

## Настройка (один раз)

1. В репозитории на GitHub: **Settings → Secrets and variables → Actions → New repository secret**
2. Имя секрета: `TELEGRAM_BOT_TOKEN`, значение — токен бота от @BotFather
3. Готово — при следующем запланированном запуске (или через **Actions → Telegram Autopost → Run workflow** для проверки прямо сейчас) пост опубликуется автоматически

## Как пополнить банк постов

Просто добавьте новые объекты в `posts_bank.json` в том же формате:
```json
{"id": 51, "category": "space", "text": "Текст поста", "photo": "https://images.unsplash.com/... или null"}
```
Следите, чтобы `id` были уникальными.

## Ограничения

- Только текст и фото (по URL, без загрузки файлов) — видео не публикуется.
- Фото должны быть с открытой лицензией (Unsplash и подобные), не с закрытыми авторскими правами.
