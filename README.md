# All Be Goods — автопостинг в Telegram

Публикует один пост в час в канал [@allbegoods](https://t.me/allbegoods) через GitHub Actions — работает в облаке GitHub, не зависит от вашего компьютера и не зависит от сети в России (запрос идёт с сервера GitHub).

## Как это устроено

Каждый час workflow сначала пробует **сгенерировать свежий уникальный пост через Anthropic API** (`generate_and_post.py`) — тема, текст и (иногда) фото каждый раз новые, контент никогда не заканчивается. Если это по любой причине не получилось (нет ключа, сбой сети, ошибка API) — автоматически подстраховывается публикацией из готового банка (`post.py`), так что пост выходит в любом случае.

- `generate_and_post.py` — просит Claude придумать пост (с той же защитой от политически чувствительных тем и требованием оригинальности текста), парсит ответ и публикует. Фото берёт из небольшого проверенного набора бесплатных фото на канале (Unsplash), сам не гуглит.
- `posts_bank.json` — запасной банк из 50 готовых оригинальных постов, у части есть привязанное бесплатное фото с Unsplash.
- `post.py` — резервный публикатор: берёт следующий ещё не опубликованный пост из банка. Когда банк заканчивается — начинает заново со случайным порядком.
- `posted_state.json` — создаётся и обновляется автоматически, хранит, что уже опубликовано из банка (коммитится обратно в репозиторий самим workflow).
- `.github/workflows/telegram-post.yml` — расписание: запуск каждый час (`cron: '3 * * * *'`), плюс кнопка ручного запуска в вкладке Actions.

## Настройка (один раз)

В репозитории на GitHub: **Settings → Secrets and variables → Actions → New repository secret** — добавить два секрета:

1. `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
2. `ANTHROPIC_API_KEY` — API-ключ с [console.anthropic.com](https://console.anthropic.com) (нужен отдельный аккаунт/биллинг, не тот же, что Claude.ai; без него просто будет всегда работать банк из `posts_bank.json`, автогенерация — не обязательна)

Готово — при следующем запланированном запуске (или через **Actions → Telegram Autopost → Run workflow** для проверки прямо сейчас) пост опубликуется автоматически.

## Как пополнить банк постов

Просто добавьте новые объекты в `posts_bank.json` в том же формате:
```json
{"id": 51, "category": "space", "text": "Текст поста", "photo": "https://images.unsplash.com/... или null"}
```
Следите, чтобы `id` были уникальными.

## Ограничения

- Только текст и фото (по URL, без загрузки файлов) — видео не публикуется.
- Фото должны быть с открытой лицензией (Unsplash и подобные), не с закрытыми авторскими правами.
