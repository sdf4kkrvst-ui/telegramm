# All Be Goods — автопостинг в Telegram

Публикует один пост в час в канал [@allbegoods](https://t.me/allbegoods) через GitHub Actions — работает в облаке GitHub, не зависит от вашего компьютера и не зависит от сети в России (запрос идёт с сервера GitHub).

## Как это устроено

Каждый час workflow публикует следующий пост из готового банка — бесплатно, без обращения к каким-либо платным API.

- `posts_bank.json` — банк из 50 готовых оригинальных постов (факты, история, юмор и т.д.), у части есть привязанное бесплатное фото с Unsplash.
- `post.py` — берёт следующий ещё не опубликованный пост из банка и публикует его. Когда банк заканчивается — начинает заново со случайным порядком.
- `posted_state.json` — создаётся и обновляется автоматически, хранит, что уже опубликовано (коммитится обратно в репозиторий самим workflow).
- `.github/workflows/telegram-post.yml` — расписание: запуск каждый час (`cron: '3 * * * *'`), плюс кнопка ручного запуска в вкладке Actions.
- `generate_and_post.py` — заготовка на будущее: если когда-нибудь захотите живую AI-генерацию вместо банка, этот скрипт уже готов, нужен только `ANTHROPIC_API_KEY` (см. ниже) и правка одной строки в workflow. Сейчас не используется.

## Настройка (один раз)

В репозитории на GitHub: **Settings → Secrets and variables → Actions → New repository secret** — добавить секрет:

- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather

Готово — при следующем запланированном запуске (или через **Actions → Telegram Autopost → Run workflow** для проверки прямо сейчас) пост опубликуется автоматически.

### Если позже захотите включить AI-генерацию

1. Заведите ключ на [console.anthropic.com](https://console.anthropic.com) (отдельный аккаунт/биллинг, не Claude.ai) и добавьте его секретом `ANTHROPIC_API_KEY`
2. В `.github/workflows/telegram-post.yml` замените строку `run: python post.py` на `run: python generate_and_post.py || python post.py` (и добавьте `ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}` в `env:`) — банк останется автоматической подстраховкой на случай сбоя генерации

## Как пополнить банк постов

Просто добавьте новые объекты в `posts_bank.json` в том же формате:
```json
{"id": 51, "category": "space", "text": "Текст поста", "photo": "https://images.unsplash.com/... или null"}
```
Следите, чтобы `id` были уникальными.

## Ограничения

- Только текст и фото (по URL, без загрузки файлов) — видео не публикуется.
- Фото должны быть с открытой лицензией (Unsplash и подобные), не с закрытыми авторскими правами.
